적었다. 다시 시도한 결과 **차단이 아니었다.** socinet.go.kr 게시판은 로그인도 캡차도 없이
`curl` 만으로 HTTP 200 을 돌려주고, 첨부파일도 같은 세션 쿠키와 `Referer` 헤더를 붙이면
그대로 받아진다. 처음 실패한 것은 서버가 막아서가 아니라 우리가 쿠키와 Referer 를 안
붙였기 때문이다. Playwright 까지 갈 필요도 없었다.

이것은 이 문서가 반복해서 경계해 온 것의 반대 방향 오류다. "검색했고 결과 없음" 과
"미검색" 을 구분하라고 적어 둔 문서가, 정작 자기 실패를 서버 탓으로 기록했다. 앞으로
"차단됨" 으로 적기 전에 최소한 쿠키·Referer·User-Agent 세 가지를 붙여 본 결과를 함께
적는다.

### 이 명부를 시설 명부로 쓰지 않는 이유

받은 것은 "지자체 연계 프로그램 지정 목록 (143개)" 이고 **사업 단위** 표다. 기관 단위로
묶으면 71행이 되는데 그 중 24행이 담당 부서(`창원시 환경정책과`, `김해시 성평등가족과`),
16행이 지자체 이름 자체(`경상남도 거제시`), 3행이 이미 틀에 있는 시설의 방 이름
(`창원시 가족센터 교육실`, `진천군 가족센터 프로그램실`)이다. 그대로 넣으면 이 프로젝트가
계속 걷어내 온 위양성을 우리 손으로 집어넣는 것이 된다. 원본은 분모와 근거로 남기고
(`kiip/kiip_local_gov_linked_programs.csv`, SKIP_ROSTERS 등재) 실제 시설 9곳만
`kiip/kiip_local_gov_linked_facilities.csv` 로 추렸다.

### 위양성 — 마주협(馬主協)

`부산경남마주협회` 와 `제주마주협회` 가 마하이주민지원단체협의회 회원단체로 공개본에
실려 있었다. 두 곳은 馬主協會, 곧 경주마 마주들의 협회이고 이주민 지원과 아무 관련이
없다. 협의회 약칭 "마주협" 이 경마 용어와 겹쳐 생긴 것이다. 규칙 11(이름이 맞는다는 것은
근거가 아니다)이 **약칭에는 더 강하게 적용된다**는 사례다.

### 아카이브가 아카이브 역할을 못 하고 있었다

위 두 곳을 걷어내려고 잘못된 명부를 `data/raw/v2/archive/` 로 옮겼는데, 공개본에 그대로
남아 있었다. `load_rosters` 가 `data/raw/v2/**/*.csv` 를 훑으면서 `archive/` 도 읽었기
때문이다. **철회한 명부가 철회되지 않는 구조**였다. 지금은 `archive/` 를 빌드에서도
건강검사에서도 제외한다.

### 파이프라인이 죽은 단계를 지나쳤다

같은 날, `code_inclusion.py` 가 `NameError` 로 죽었는데 파이프라인이 끝까지 돌고
`everything checked passed` 까지 찍었다. 실행 스크립트가 `python ... | tail -24` 형태여서
파이프의 종료코드가 `tail` 의 것이 되고 `set -e` 가 만족돼 버린 것이다. 그 결과 하류 전부가
**직전 실행의** `inclusion_coded.csv` 로 빌드됐고, 사람이 판정한 56건이 반영되지 않았으며,
어느 줄도 그것을 말하지 않았다. 실행 스크립트를 고쳐 단계가 죽으면 `STEP FAILED` 를 찍고
멈춘다.

## E-4. data.go.kr 인증키로 풀린 것과 풀리지 않은 것 (2026-08-20)

`DATA_GO_KR_KEY` 가 발급되어 한국사회보장정보원 사회복지시설정보 OpenAPI
(`apis.data.go.kr/B554287/sclWlfrFcltInfoInqirService1`)에 접근했다. 오퍼레이션 여섯 개,
각 일일 1만 건.

**인증키는 URL 인코딩된 형태로 발급된다.** `requests` 의 `params` 로 그대로 넘기면 한 번
더 인코딩되어 서명이 깨진다. 반드시 `urllib.parse.unquote` 로 디코딩해서 넘긴다. 이
API 에서 가장 흔한 실패 원인이다.

### 얻은 것

`getFcltKindCodeInfoInqire` 가 시설종류 **259개의 전체 목록**을 준다. 분모가 무엇인지를
추측하지 않아도 된다는 점에서 이 오퍼레이션 자체가 값어치가 있다.

이주민을 직접 대상으로 하는 종류에서 실제로 자료가 나오는 것은 `140101 다문화가족지원센터`
**218곳**(시설 목록) / **229곳**(시설별 기본정보)뿐이다. 우리 가족센터 명부와 대조한 결과
**신규는 없고**, 이름 표기 차이를 빼면 커버리지가 사실상 완전하다는 것이 확인됐다. 대신
시설마다 정부가 부여한 `fcltCd` 와 도로명주소·전화·법인명·설립일이 붙는다.

`enrich_from_ssis.py` 가 이것을 세 갈래로 나눈다. 틀에 주소가 없어 채운 것 1건, 같은
필지인데 등록부가 더 상세한 것 52건, **다른 필지를 가리키는 것 70건**. 마지막 것은
덮어쓰지 않고 `review_address_conflict.csv` 로 뺐다. 등록부가 정부 것이라는 이유만으로
덮어쓰면 이미 이전한 센터를 옛 주소로 되돌릴 수 있다.

### 주소 비교가 깨져 있었다

처음에는 충돌이 160건으로 나왔다. 우리 주소는 카카오 필지 키(`4715010500-320-16`)를
쓰는데 SSIS 주소는 정규화 표에 없어서 정규식 키(`평화길134`)로 떨어졌고, 같은 건물을
서로 다른 종류의 키로 비교하고 있었다. SSIS 주소 223개를 같은 필지 표에 넣으니 160 → 70
으로 줄었다. **정규화 표를 쓰는 코드는 표에 없는 문자열이 들어올 때 무엇으로 떨어지는지를
항상 확인해야 한다.**

### 얻지 못한 것

- **여성가족부 계열이 이 시스템에 없다.** 가정폭력상담소, 성폭력피해상담소, 통합상담소,
  여성긴급전화, 여성인력개발센터, 성매매피해지원시설 외국인지원시설 모두 `totalCount=0`
  이다. 보건복지부 시스템이기 때문이다.
- **어떤 사업을 하는지가 없다.** `getFcltByBassInfoInqire` 는 주소·전화·법인명·설립일만
  준다. 그래서 자료가 있는 `020111 지역아동센터` 3,557곳을 이주민 지원기관으로 넣을 수
  없다. 이름도 사업도 이주민을 말하지 않으므로 규칙 11에 걸리고, 넣으면 학교 964곳 때와
  같은 위양성이 3.5배 규모가 된다.

### 구인정보가 사업을 말한다

`getFcltByJoInfo` 는 현재 채용공고 986건을 주고 직무내용(`dtyCntn`)이 들어 있다. 이중언어
코치, 통번역 전담인력, 중도입국 청소년 사업 담당자를 뽑는 공고는 **그 기관이 이주민 사업을
한다는 문서 근거**다. 이번 회차 수확은 기관 7곳이고 그 중 5곳은 이미 틀에 있었다. 새로
확인된 것은 김해시종합사회복지관 한 곳으로, 일반 종합사회복지관이 공동모금회 기획사업으로
중도입국 청소년 사업을 하는 경우다.

한 번에 많이 얻는 방법이 아니라 **주기적으로 돌리는 방법**이다. 공고는 계속 바뀌므로
분기마다 돌리면 일반 복지시설이 이주민 사업을 맡는 것을 잡아낼 수 있다.

여기서도 어휘 충돌이 있었다. `통역` 으로 거르면 **수어통역센터** 7곳이 걸린다. 청각장애인
통역이고 이주민 통역이 아니다. 마주협(馬主協) 때와 같은 종류의 오류라 `수어|수화|청각장애|
농아` 를 명시적으로 배제한다.

`getFcltByEvntInfo`(행사정보)는 전국 34건뿐이고 2022년 자료라 쓸 수 없다.

### 페이지네이션이 동작하지 않는다

`getFcltByJoInfo` 는 `pageNo` 를 무시하고 매번 전체를 돌려준다. 페이지를 세어 반복하면
같은 986건을 열 번 받아 9,860행이 된다. 받은 뒤 `seq` 와 `fcltCd` 로 중복을 제거해야 한다.
