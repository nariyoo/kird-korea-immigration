# 재원과 운영주체 코딩

`scripts/v2/code_governance.py` 가 만드는 두 변수의 정의와 근거.

## 왜 필요한가

자원지도가 기관의 위치만 보여 주면 전달체계 연구가 실제로 묻는 질문에 답할 수 없다.
어떤 지역이 국가가 직접 운영하는 관서로 덮여 있는 것과, 국가가 다른 법인과 맺은 계약으로
덮여 있는 것과, 국가 없이 사람들이 조직해서 버티고 있는 것은 예산 한 줄이 움직일 때
전혀 다른 일이 된다. 기관 수만 세면 이 셋이 같아 보인다.

## 두 변수인 이유

하나로 합치면 실재하는 구분이 사라진다.

| `gov_funder` | 뜻 |
|---|---|
| `central` | 중앙정부 |
| `local` | 지방자치단체 |
| `central_local` | 중앙·지방 매칭 (국고보조사업) |
| `private` | 민간 자체 재원 |
| `religious` | 종교기관 |
| `academic` | 대학 |
| `unknown` | 확인 안 됨 |

| `gov_operator` | 뜻 |
|---|---|
| `direct` | 직영. 재원 주체가 직접 운영 |
| `contracted` | 위탁. 재원 주체가 다른 법인에 맡김 |
| `designated` | 지정. 기관이 자기 재원으로 운영하되 정부가 지정 |
| `self` | 자체. 정부 재원 없음 |
| `unknown` | 확인 안 됨 |

의미를 나르는 것은 두 값의 조합이다. 가족센터는 `central_local` + `contracted` 이다.
돈은 국고보조 매칭이고 문은 시군구가 고른 법인이 연다. 사회통합프로그램 운영기관은
`central` + `designated` 이다. 법무부가 지정하고 프로그램 단위로 지급하지만, 그 대학이나
단체는 지정 이전부터 있었고 지정이 없어도 존재한다. 둘을 "정부"로 합치면 어떤 지역에
국가 공급이 있다고 말하게 되는데, 실제로 있는 것은 이미 거기 있던 기관에 붙은 지정이다.

## 근거의 순서

**1순위는 명부다.** 명부 하나하나가 곧 지정이거나 재원 프로그램이기 때문이다. 가족센터가
성평등가족부 목록에 있는 것은 부처가 사업비를 대고 시군구가 법인에 위탁하기 때문이고,
출입국·외국인사무소가 법무부 목록에 있는 것은 부처가 직접 운영하기 때문이며, 어떤 단체가
NPAS 등록부에 있는 것은 스스로 등록했기 때문이다. 명부를 읽는 것이 곧 그 배치를 읽는 것이다.

**2순위는 `unit_type`** 이고, 위 표에 없는 명부에서만 온 행에 쓴다.

**3순위는 운영주체 자유기술 칸이다.** `operator_type` 은 2,800행 중 1,265행이 비어 있고
나머지는 `public`, `NGO`, `정부`, `사단법인`, `시민단체` 를 두 언어로 섞어 쓴다. 이 칸을
1순위로 두면 코딩이 아니라 표기 습관을 재현하게 된다. 다만 `operator_name` 에는
"재단법인 ○○복지재단(위탁운영)" 처럼 위탁 여부가 적혀 있는 경우가 많아서, 명부가 비워 둔
값을 채우는 데만 쓴다. **이미 정해진 값을 덮어쓰지 않는다.**

공개 1,740곳 기준 근거 분포는 명부 1,365, `unit_type` 229, 운영주체 기술 62, 근거 없음 84.
행마다 `gov_basis` 칸에 무엇으로 정했는지 남는다.

## 남겨 두는 것

지자체 조례로 설치한 시설은 조례만으로 직영인지 위탁인지 알 수 없다. 명부가 운영주체를
적어 두었으면 그것이 답이고, 안 적어 두었으면 `unknown` 으로 남긴다. 공개본에서 70곳이
`지자체 / 확인 안 됨` 이고 84곳은 두 칸 모두 확인 안 됨이다. 추정해서 채우면 분포가
깨끗해지지만 그 깨끗함은 자료가 아니라 코딩자가 만든 것이 된다.

대학이나 교회가 자기 돈으로 운영하는 곳은 `self` 로 둔다. 자체 재원이면 위탁할 상대가
없으므로, 이 경우까지 `unknown` 으로 두면 없는 결측을 보고하게 된다.

서울의 기관 수는 가장 많은 축에 들지만 그 중 62%가 민간·종교·대학 재원이다. 충청남도와
세종은 반대쪽 끝에 있다. 기관 수만 세면 서울이 잘 갖춰진 지역으로 보이고, 재원을 함께
보면 서울의 공급이 국가 예산과는 다른 것에 의존하고 있다는 것이 드러난다.

이 표를 읽을 때의 제약 두 가지. 첫째, `unknown` 84곳이 분모에 들어 있으므로 국가재원
비중은 하한이다. 둘째, 기관 수는 규모를 반영하지 않는다. 직원 두 명인 단체와 30명인
가족센터가 각각 1로 세어진다. 규모 변수는 아직 없다.
